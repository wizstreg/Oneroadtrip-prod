1Votre demande

Décrivez le voyage que vous voulez : thématique, durée, point de départ, contraintes. Vous pouvez aussi coller une carte ou un brief existant à compléter. L'architecte vous proposera un squelette d'itinéraire.

Le prompt sera affiché ci-dessous. Copiez-le dans Claude/ChatGPT/Gemini pour obtenir un squelette d'itinéraire.

✦Itinéraire créateur

Collez le JSON reçu d'un créateur (schema creator-v1). Le prompt généré demande à l'IA de nettoyer les textes, géocoder les coordonnées manquantes, estimer les durées, rédiger le SEO, la meta et le pacing, tout en gardant les liens, le template et les couleurs du créateur. Vous récupérez un JSON createur-v1 nettoyé (racine itins, source:"creator"). ⚠ À placer dans creators\fr\ et à générer avec generate-v5. NE JAMAIS le passer dans l'import standard countries : la chaîne classique lui collerait vos photos de catalogue à la place de celles du créateur.

Le prompt s'affiche plus bas. La réponse de l'IA sera un JSON propre à coller dans l'import.

⬇Page HTML → itinéraire

Un créateur vous a envoyé le HTML de son article (par e-mail). Collez-le ici : le prompt généré demande à l'IA d'en extraire un itinéraire au format creator-v1, en gardant ses textes, ses liens affiliés en clair et les URLs de ses images. Vous passez ensuite le JSON obtenu dans la box « Itinéraire créateur » ci-dessus pour le compléter.

Marche bien si l'article est structuré (une section par étape, liens en clair, vraies images). Sinon, le résultat sera partiel.
